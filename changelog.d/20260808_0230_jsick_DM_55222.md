### Bug fixes

- Fixed the schedules of the worker's two daily cron jobs, `cleanup_scheduled_runs` and `reconcile_github_names`. Both declared only the hour they were meant to run at, and arq treats an unset cron field as a wildcard rather than as zero, so each fired every minute of that hour — sixty runs a day instead of one. For `reconcile_github_names` that meant sixty times the intended GitHub API load. Both now pin `minute=0`, and a test counts each cron job's firings over a full day so the mistake cannot recur.
