### Other changes

- Times Square now handles GitHub's `repository` transferred webhook. When a repository moves to another owner that Times Square syncs from, a new `repo_transferred` worker task rewrites the owner, owner ID, and repository name stored on that repository's pages in a single bulk update, so the pages immediately serve from their new URLs without re-syncing anything from GitHub or re-executing any notebook. When a repository is transferred to an owner that is *not* in `TS_GITHUB_ORGS` it has left Times Square's remit, and its pages are soft-deleted just as they are when the app is uninstalled from the repository. In both cases the pages are matched on the stable numeric repository ID alone, with no fallback to the stored owner and repository names: GitHub frees the old `owner/repo` name pair the moment a transfer happens, so a name-keyed match risks catching the pages of whatever repository claims that name next. Pages that predate numeric-ID capture are healed by the repository's next sync instead.
