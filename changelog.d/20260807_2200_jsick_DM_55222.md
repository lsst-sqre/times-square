### Other changes

- Times Square now handles GitHub's `installation_target` renamed webhook, which GitHub sends when the account a Times Square installation sits on — an organization or a personal account — is renamed. A new `owner_renamed` worker task flips the owner login stored on that account's pages in a single bulk update, keyed on GitHub's stable numeric owner ID with a fallback to the old login for pages that predate ID capture, so the pages immediately serve from their new URLs without re-syncing anything from GitHub or re-executing any notebook. Because `TS_GITHUB_ORGS` is keyed on login names, the allowlist still names the account by its *old* login when this event arrives; the webhook is therefore accepted when either the old or the new login is allowlisted, and the task logs a warning reminding the operator to update `TS_GITHUB_ORGS` to the new login. The Times Square GitHub App must now subscribe to the `installation_target` event, which requires no additional permission. GitHub's `organization` renamed event reports the same rename for organizations, but it is gated behind the **Members** organization permission — which every installing organization's owner would have to approve — and never fires for a personal account, so `installation_target` is used instead.
