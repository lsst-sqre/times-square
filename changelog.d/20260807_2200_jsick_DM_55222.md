### Other changes

- Times Square now handles GitHub's `organization` renamed webhook. A new `org_renamed` worker task flips the owner login stored on the organization's pages in a single bulk update, keyed on GitHub's stable numeric owner ID with a fallback to the old login for pages that predate ID capture, so the pages immediately serve from their new URLs without re-syncing anything from GitHub or re-executing any notebook. Because `TS_GITHUB_ORGS` is keyed on login names, the allowlist still names the organization by its *old* login when this event arrives; the webhook is therefore accepted when either the old or the new login is allowlisted, and the task logs a warning reminding the operator to update `TS_GITHUB_ORGS` to the new login. The Times Square GitHub App must now subscribe to the `organization` event, which GitHub gates behind the **Members** organization permission (read-only); on an existing app that permission must be approved by an owner of each installing organization before the event is delivered.
