### Other changes

- Times Square now records GitHub's stable numeric IDs for the repository, its owner, and the Times Square GitHub App installation on every GitHub-backed page (new nullable `github_repository_id`, `github_owner_id`, and `github_installation_id` columns, with an index on the repository ID). Every repository sync — from a push or from an app installation — captures those IDs and refreshes the stored owner and repository name strings, so a rename that Times Square missed while it was offline heals itself on the next sync: the repository's pages are matched by their rename-proof repository ID and their names are brought up to date in place, instead of being orphaned under the old name. Pages that predate ID capture are still matched by name until an ID is recorded for them.
