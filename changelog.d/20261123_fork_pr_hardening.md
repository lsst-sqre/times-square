### Other changes

- Times Square now explicitly refuses to check notebooks from forks. Before creating or re-running GitHub check runs, the worker verifies that the repository's owner is in `TS_GITHUB_ORGS` and that the head commit is on a branch of the repository: either the head of a branch, or in the history of the branch it was pushed to or of the default branch. A fork's commits are on none of the repository's branches, while commits that arrived through a merged pull request from a fork, and commits in an installed repository that is itself a fork, are still checked. Previously, forks were excluded only as a side effect of GitHub sending `check_suite` webhook events solely for commits pushed to the repository where the app is installed.
