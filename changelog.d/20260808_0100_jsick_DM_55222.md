### New features

- Times Square now reconciles the GitHub owner and repository names stored on its pages against GitHub once a day. A new `reconcile_github_names` worker cron re-reads every repository behind a live page from the GitHub API — by GitHub's stable numeric repository ID, which no rename or transfer changes — and rewrites the stored names in a single bulk update whenever they disagree with GitHub's answer. This heals a rename that happened while Times Square was down, or whose webhook delivery failed, instead of leaving the repository's pages orphaned under their old names until the repository's next push. Like the rename webhooks it is a pure name flip: nothing is re-synced from GitHub and no notebook is re-executed. A repository the GitHub App cannot read is logged with the status code GitHub returned and its pages are left exactly as they are — a deleted repository, an uninstalled app, and a transient authentication failure are indistinguishable from the cron's vantage point, so it never deletes anything — and a repository whose current owner is no longer in `TS_GITHUB_ORGS` is reported rather than healed into an organization Times Square does not sync from. Each run logs one summary line with its checked, healed, skipped, and failed repository counts.
