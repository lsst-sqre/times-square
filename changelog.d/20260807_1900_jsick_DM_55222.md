### Other changes

- Times Square now handles GitHub's `repository` renamed webhook. When a repository is renamed, a new `repo_renamed` worker task flips the repository name stored on all of that repository's pages in a single bulk update, matching them by their stable numeric repository ID (falling back to the old name for pages that predate ID capture), so the pages immediately serve from their new URLs. Because a rename does not change the repository's content, nothing is re-synced from GitHub and no notebook is re-executed; the existing cached renders are kept. The number of pages affected is reported in the worker's structured logs.
